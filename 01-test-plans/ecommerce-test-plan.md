# Test Plan – E-Commerce Web Application

## 1. Objective
The objective of this test plan is to ensure the quality, stability, and functionality of the e-commerce application before release.

---

## 2. Scope

### In Scope
- User Registration & Login
- Product Search and Filters
- Shopping Cart Management
- Checkout Process
- Payment Integration
- Order Confirmation

### Out of Scope
- Performance Testing (handled separately)
- Security Penetration Testing

---

## 3. Test Types
- Smoke Testing
- Functional Testing
- Regression Testing
- Exploratory Testing
- API Testing
- Cross-Browser Testing

---

## 4. Test Environment
- QA/Staging Environment
- Browsers: Chrome, Firefox, Edge
- Devices: Desktop + Mobile Responsive

---

## 5. Entry Criteria
- Build deployed successfully
- Requirements approved
- Test data available

---

## 6. Exit Criteria
- No open Critical/Blocker defects
- Regression suite passed successfully
- Test Summary Report completed

---

## 7. Deliverables
- Test Cases
- Bug Reports
- Test Execution Report
- QA Sign-off Document
